# Markdown Studio (نمایش‌دهنده و مبدل مارک‌داون برای ویندوز) 📝✨

یک برنامه شیک، مینیمال و کلاسیک برای نمایش، ویرایش و تبدیل فایل‌های مارک‌داون (`.md`) با قابلیت درگ اند دراپ، تایپوگرافی دوزبانه (فارسی و انگلیسی)، دریافت هوشمند فونت از **Google Fonts** و صدور مستقیم به صورت **PDF** و **Text**.

---

## 🌟 ویژگی‌های کلیدی (Key Features)

- 📂 **درگ اند دراپ آسان (Drag & Drop):** کشیدن و رها کردن فایل‌های `.md`، `.markdown` و `.txt` در هر جای پنجره برنامه با بارگذاری آنی.
- 🎨 **دیزاین کلاسیک، ادیتوریال و مینیمال:** طراحی آرکیتکچرال بدون افکت‌های شیشه‌ای و نئونی آزاردهنده؛ با ترکیب رنگ‌های آرامش‌بخش، گرم و ارگونومیک برای مطالعه و نگارش طولانی.
- 🌓 **تم‌های تاریک و روشن (Dark & Light Modes):** 
  - **تم تاریک کلاسیک (Classic Dark):** زغالی مات گرم با اکسنت‌های ملایم سفالی.
  - **تم روشن کتان (Linen Light):** پس‌زمینه کتان با کاغذ کتابی و متن جوهری عمیق.
- 🔤 **سیستم جامع تایپوگرافی و فونت‌های محبوب:**
  - **فونت‌های معروف فارسی:** وزیرمتن (Vazirmatn)، ساحل (Sahel)، شبنم (Shabnam)، صمیم (Samim)، پرستو (Parastoo)، گندم (Gandom)، تنها (Tanha)، نسخ (Noto Naskh)، لاله‌زار (Lalezar) و فونت سیستمی.
  - **فونت‌های معروف انگلیسی:** Inter، Merriweather، Lora، Playfair Display، Cinzel، JetBrains Mono، Fira Code، Georgia و System Sans.
- 🌐 **اتصال هوشمند به Google Fonts API:**
  - امکان جستجو و افزودن هر فونت دلخواه از گوگل فونتز.
  - مدیریت هوشمند خطاها به زبان ساده و قابل فهم (تشخیص قطعی اینترنت، اشتباه در املای فونت یا فیلترینگ و اختلال شبکه بدون اصطلاحات گیج‌کننده برنامه‌نویسی).
  - ذخیره‌سازی خودکار فونت‌های دریافتی در حافظه دستگاه (`localStorage`).
- 📄 **خروجی چندگانه و باکیفیت:**
  - **خروجی PDF مستقیم:** دانلود فوری فایل `.pdf` برداری و باکیفیت.
  - **چاپ ویندوز (Microsoft Print to PDF):** صفحه‌بندی تمیز استاندارد بدون دکمه‌های رابط کاربری.
  - **خروجی متن خالص (.txt):** حذف هوشمند کدهای مارک‌داون و استخراج متن تمیز.
  - **خروجی مارک‌داون (.md) و وب مستقل (.html)**.
  - **کپی سریع Rich Text:** برای پیست مستقیم و فرمت‌شده در Microsoft Word یا پیام‌رسان‌ها.
- 📑 **فهرست عناوین خودکار (Table of Contents):** استخراج هوشمند تیترهای H1 تا H6 با امکان پرش سریع با اسکرول نرم.
- 📊 **نوار وضعیت حرفه‌ای:** نمایش تعداد کلمات، کاراکترها، سطرها، تخمین زمان مطالعه و تشخیص خودکار جهت متن (RTL / LTR).
- ⌨️ **حالت‌های نمایش:** فقط پیش‌نمایش (Preview)، نمای دوتایی (Split View با ویرایشگر همزمان) و کد خام (Raw).

## 🚀 راهنمای نصب و اجرا روی ویندوز (Quick Start)

### پیش‌نیاز
نرم‌افزار رایگان **Node.js** (نسخه ۱۸ یا بالاتر) از سایت رسمی [nodejs.org](https://nodejs.org).

### ۱. کلون یا دانلود مخزن
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### ۲. نصب بسته‌ها
```bash
npm install
```

### ۳. اجرای برنامه
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
```text
http://localhost:3000
```

## 💻 نصب به عنوان نرم‌افزار مستقل دسکتاپ (PWA)

برای اینکه برنامه مانند نرم‌افزارهای بومی ویندوز (مثل Word و Notepad) آیکون اختصاصی روی دسکتاپ داشته باشد و در یک پنجره مستقل بدون نوار ابزار مرورگر باز شود:

1. در مرورگر **Microsoft Edge** یا **Google Chrome** وارد برنامه شوید.
2. روی منوی سه‌نقطه بالای سمت راست مرورگر کلیک کنید.
3. بخش **Apps** (یا برنامه‌ها) را انتخاب کنید.
4. روی گزینه **«Install this site as an app»** کلیک کنید.
5. آیکون برنامه روی دسکتاپ شما اضافه می‌شود!

| کلید میانبر | عملکرد |
| :--- | :--- |

## 🛠️ تکنولوژی‌های استفاده شده (Tech Stack)

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 (Classic Editorial & Minimalist palette)
- **Markdown Engine:** Marked + DOMPurify (Sanitized HTML)
- **Code Highlighting:** Highlight.js (Muted Classic Theme)
- **PDF Generation:** jsPDF + html2canvas + Native Print CSS Rules
- **Typography:** Google Fonts CSS2 API + Rastikerdar Community Fonts
- **Icons:** Lucide React
